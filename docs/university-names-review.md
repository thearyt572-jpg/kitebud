# University names: full names in English and Khmer

Updated 2026-11-05. Owner's decision (2026-11-05): **every university is shown with its full name**, in English mode and in Khmer mode.

**Status: all 15 names are decided.** The names are in `tools/propose-university-links.js` (`FULL_NAMES`), and `js/universities.js` has been rebuilt from it on the branch `feature/university-names`. They are **not on the live site yet**: the live site (`main`) still shows the short names from the sheet until this branch is committed and merged.

## Owner's decisions (2026-11-05)

1. **English:** use the 15 full English names below.
2. **Khmer, from official websites:** use the 6 Khmer names that the universities' own websites show (ITC, BELTEI, RULE, UC, SETEC, NUM).
3. **Khmer, from the owner:** the other 9 Khmer names were given by the owner: RUPP, CADT, AUPP, Paragon, UTE, CamTech, CamEd, Norton, IU. They are used exactly as written, with one correction:
   - **UTE:** the owner's text wrote «សាកលវិទ្យាល័័យ» with the vowel sign ័ twice; it is written once («សាកលវិទ្យាល័យ»). The second ័ is a typing slip that browsers draw as a stray mark.
4. **SETEC:** use the official spelling "SETEC Institute" instead of the sheet's "SeTech Institute"; its round badge reads "SETEC" (it was "STI").
5. **The round badge** keeps the short name for the other 14 (ITC, RUPP, CADT…).

## Where the names come from

- **English names** were copied exactly as each university's own website writes them (2026-11-05). Nothing was translated or guessed.
- **Khmer names** come from the university's own website where it shows one, otherwise from the owner (column "Khmer source").
- `js/universities.js` is generated by `tools/propose-university-links.js`. Names must be changed there, then rebuilt with `node tools/propose-university-links.js --build`; never edit the generated file by hand.

## Notes and open points

These do not block using the names above. Each is listed so nobody mistakes it for a confirmed fact.

1. **CADT (not an error, a difference in meaning):** the owner's Khmer name «វិទ្យាស្ថានបច្ចេកវិទ្យាឌីជីថល» means "Institute of Digital Technology", while the official English name uses "Academy" ("Cambodia Academy of Digital Technology"). The owner's Khmer is used as given.
2. **CamEd's English name is not verified on its official website.** "CamEd Business School" comes from Wikipedia and directories, because cam-ed.edu.kh blocked automated access. Open: check it on the official website.
3. **Norton has no official website in the data.** The sheet's website column is empty for Norton, so the report shows no "Official website" link for it. norton-u.com names itself Norton University, but it is not in the sheet and was not confirmed as the official site. Open: add the website to the sheet if wanted.
4. **Not live yet.** The full names reach students only after `feature/university-names` is committed, merged into `main` and deployed.

## How the names were added (done 2026-11-05)

1. The confirmed names are stored in one table, `FULL_NAMES`, in `tools/propose-university-links.js`. The sheet's short name is used only where a university has no entry, and still drives the round badge (except SETEC's, decision 4).
2. `js/universities.js` was rebuilt with `node tools/propose-university-links.js --build`, never edited by hand.
3. Compared with the previous file, only the names changed: `en` for 14 universities (Norton's name was already full), `km` for all 15, and the badge for SETEC. Ids, websites, cities, scholarships, logos, logo permissions, verification dates and all 214 programs are unchanged.
